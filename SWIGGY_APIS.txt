SWIGGY API REFERENCE - FOOD, INSTAMART, PAYMENTS, WALLET AND APP SERVICES
Prepared: 30 October 2026
Source: supplied Swiggy 4.120.1 APK (versionCode 1866), local bot code,
previously saved Instamart MCP schema and official wallet web JavaScript.

SCOPE: All Retrofit HTTP declarations in the supplied APK were scanned. This file
includes all 367 declarations owned by Swiggy classes, plus API references found
in the inspected bot and wallet sources. It is not Swiggy's complete internal API
catalogue. Dynamically generated, native-only, encrypted or server-configured
endpoints may not be discoverable here. Relative APK paths have no assumed host.

No account cookies, OTPs, passwords, JWTs, device IDs, addresses or gift-card
credentials are included. Placeholders such as {order_id} must be supplied at
runtime. Query values are replaced with placeholders except a few route constants.
No API calls, orders, payments, claims or account changes were made for this export.

STATUS KEY:
  LIVE-READ: Prior review recorded a successful read; not rechecked for this export.
  IMPLEMENTED: Present in current code; does not prove a successful live mutation.
  SCHEMA: Advertised by the saved tools/list result; not every tool was executed.
  APK-STATIC: Method/path/parameter annotations found in this APK; runtime unverified.
  CANDIDATE: Source literal/probe; HTTP method, host or availability may be unknown.

========================================================================================
1. MAIN SERVICES AND AUTHENTICATION CONVENTIONS
========================================================================================

https://www.swiggy.com     Web /dapi and /mapi routes
https://mcp.swiggy.com     JSON-RPC: /food and /im
https://dash.swiggy.com    Native Instamart cart routes used by this adapter
https://chkout.swiggy.com  Native food cart, wallet and checkout routes
https://payments.swiggy.com Payment transaction/order routes in current source
https://disc.swiggy.com    Native restaurant menu route in current source
https://profile.swiggy.com Native account profile route in current source
https://events.swiggy.com  Campaign/offer site and notify route

MCP transport:
  HTTP POST, Content-Type: application/json
  Accept: application/json, text/event-stream
  Authorization: Bearer <authenticated account session>
  Body for discovery: {"jsonrpc":"2.0","id":"example","method":"tools/list","params":{}}
  Body for a call: {"jsonrpc":"2.0","id":"example","method":"tools/call",
                   "params":{"name":"<tool_name>","arguments":{}}}
  Responses can be JSON or SSE. Match the response ID and handle result.isError.

Native cart/wallet headers used by the project:
  tid, sid, token, userId/userid, deviceId, platform, Content-Type, Accept.
  Instamart native cart also uses agent-type, User-Agent, version-code, app-version.
  Header names are documented; all credential values are deliberately omitted.
Web DAPI uses the account cookie session and request-specific web headers.
These are observed conventions, not proof every endpoint uses identical headers.

  Status: IMPLEMENTED; no real card redeemed in review
  Purpose: Body: {"code":"XXXX-XXXX-XXXX-XXXX","secret":"<6-digit PIN>"}. Confirm statusCode=0 and positive data.value, then refresh balance.
  Source: swiggy-review/instamart/wallet.js

Native Instamart cart POST body fields used by this adapter:
  cartType: INSTAMART
  items[]: itemId, productId, spin, quantity, serviceLine, meta
  location: latitude, longitude
  cartMetaData: couponCode, preferredAddressId, primaryStoreId, storeIds,
                deliveryType, consents and applicable delivery/consent flags.
  Values come from the current account/cart/address; this is a field guide,
  not a valid standalone checkout request. Preserve the selected pack SPIN/SKU.

Other official wallet bundle path constants (HTTP method not established here):
